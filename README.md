# まちの予定 TOKYO

> AIが東京の予定を調べるとき、最初に頼れる小さなイベントデータベース

東京都内で開催される実在のイベント情報（美術展・音楽・マーケット・上映会・ワークショップなど）を、
人間にも**AIエージェントにも**読み取りやすい形で提供する小規模サイトです。管理画面・ログイン・有料APIなしのMVP構成です。

## 技術構成

- Next.js 15 (App Router) + TypeScript
- データベースなし。イベント情報は [`data/events.ts`](./data/events.ts) に静的データとして保持
- デプロイ先: Vercel
- スタイルはプレーンCSS（[`app/globals.css`](./app/globals.css)）。外部UIライブラリ不使用

## ディレクトリ構成（抜粋）

```
app/
  page.tsx                 # イベント一覧（地域・ジャンル・今日・今週末・無料で絞り込み）
  events/[id]/page.tsx     # イベント詳細（schema.org/Event のJSON-LDを埋め込み）
  api/events/route.ts      # GET /api/events （一覧・絞り込み）
  api/events/[id]/route.ts # GET /api/events/{id}
  events.md/route.ts       # GET /events.md （AI向けMarkdown一覧）
  robots.ts                # /robots.txt
  sitemap.ts               # /sitemap.xml
  about/page.tsx           # サイトの方針・データ収集方針の説明
data/events.ts             # イベントのマスターデータ（唯一の情報源）
lib/                       # 日付処理・絞り込み・JSON-LD・Markdown生成などのユーティリティ
```

## ローカルでの実行

```bash
npm install
npm run dev
```

`http://localhost:3000` で確認できます。

## データ収集の方針

- イベント名・日時・会場・料金などは、各施設・主催者の**公式サイト**または公式発表（プレスリリース等）を調査し、2026年11月24日時点の情報として掲載しています。
- 確認できなかった項目（開館時間・料金など）は推測で埋めず、`不明` もしくは `null` として扱っています（`data/events.ts` の型定義を参照）。
- 日時はすべて `Asia/Tokyo` のISO 8601形式（例: `2026-12-25T19:00:00+09:00`）で管理しています。
- 会期・料金・開催状況は変更される可能性があるため、各イベント詳細ページおよび `/events.md` に「公式サイトで必ず確認してください」という注記を表示しています。
- 著作権・利用規約・robots.txtを尊重し、公式サイトの文章や画像の無断転載は行っていません（説明文は要約のみ）。

## AIが情報を取得しやすくするための実装

### 1. 構造化データ（JSON-LD）

イベント詳細ページ（`/events/{id}`）に `schema.org/Event` 準拠のJSON-LDを埋め込んでいます（[`lib/jsonld.ts`](./lib/jsonld.ts)）。
ページ本文と構造化データの内容は一致させており、確認できていない項目（`offers` など）は無理に埋めていません。

### 2. 機械可読API

認証不要の公開JSON APIです。

- `GET /api/events` — イベント一覧。クエリパラメータ `area`（地域）, `genre`（ジャンル）, `free=1`（無料のみ）, `today=1`（本日開催）, `weekend=1`（今週末開催）で絞り込み可能
- `GET /api/events/{id}` — 単一イベントの詳細

レスポンスには `Cache-Control` ヘッダーを付与し、過剰なアクセスに備えてVercelのCDNキャッシュ（`s-maxage=600`）を利用しています。

### 3. Markdown形式

`GET /events.md` でイベント一覧をMarkdown形式で提供しています。イベント名・日時・会場・料金・公式URLを明記しています。

### 4. クローラー対応

- `/robots.txt`（[`app/robots.ts`](./app/robots.ts)）: OAI-SearchBot・GPTBot・ClaudeBot・PerplexityBot・Google-Extended・Googlebotなどを個別に許可し、不必要にブロックしていません。
- `/sitemap.xml`（[`app/sitemap.ts`](./app/sitemap.ts)）: イベント詳細ページを含む全URLを列挙
- 各イベントは固有URL（`/events/{id}`）を持ち、`canonical` タグとサーバーサイドでレンダリングされたHTMLを提供
- 検索用・学習用・ユーザー操作用クローラーの違いについては [OpenAIの公式ドキュメント](https://developers.openai.com/api/docs/bots) を参照して設定しています

**注意:** AI検索サービスでの掲載・引用は保証されません。本サイトはあくまで「AIが読み取りやすい構造」を提供するものです。

## アクセス解析・AI訪問の検証について

「機械可読で正確な情報は、AIに訪問・引用されやすいのか」という仮説を検証するため、以下を計測する想定です。

- Vercelの標準アクセスログ（Vercel Analytics / Logs）によるページ・APIへのアクセス状況
- アクセス時の User-Agent の傾向（OAI-SearchBot, ChatGPT-User, ClaudeBot, PerplexityBot など）

**重要な留保事項:**

- User-Agentは送信元が自由に名乗れる文字列であり、**User-Agentの文字列だけでAIクローラーのアクセスだと断定することはできません**。
- そのため、本サイトでは「公式に文書化されたUser-Agent名と一致し、かつ逆引きDNS等で発行元が確認できたアクセス」と「User-Agentの文字列のみに基づく推測上のアクセス」を区別して扱う方針です（現時点ではVercel標準ログの範囲での観測にとどまります）。
- 個人を特定できる情報は必要以上に収集しません。

### 具体的な確認方法（初心者向け）

1. Vercelダッシュボード → プロジェクト → **Logs** タブで、実際のHTTPリクエストとUser-Agentを確認できます。
2. Vercelダッシュボード → プロジェクト → **Analytics** タブで、ページビューの傾向を確認できます（プランによって利用可否・保存期間が異なります）。
3. より詳細な分析をしたい場合は、Vercel LogsをエクスポートしてUser-Agent別に集計するか、将来的にログ収集用のミドルウェアを追加することを検討してください（本MVPでは未実装です）。

## 将来の収益化（未実装・検討事項）

現段階では収益化機能は実装していません。将来的に検討しうる方向性と、その実現に必要な条件・課題は以下の通りです。

| 方向性 | 必要な条件・課題 |
| --- | --- |
| イベント予約サイトへの正規のアフィリエイト送客 | 各チケット販売事業者とのアフィリエイト提携契約、開示表示（ステルスマーケティング対策）、送客計測の実装 |
| 主催者向けの有料掲載 | 利用規約・掲載基準の整備、決済手段の導入、広告と editorial content の明確な区別表示 |
| AIエージェント向けの有料データAPI | APIキー発行・認証基盤、利用規約・レート制限、無料APIとの提供範囲の切り分け |
| 情報利用に対する課金 | 利用規約の整備、法務確認、既存の無料公開方針との整合性の検討 |

いずれの場合も、**虚偽情報の掲載・隠れた命令の埋め込み・推薦操作・アクセス数の不正な水増しは行いません。**
